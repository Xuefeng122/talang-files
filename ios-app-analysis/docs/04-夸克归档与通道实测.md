## 为什么自动通道下不了

根因不是「有没有网盘工具」，而是**本机没有任何夸克网页账号会话**，而服务端对「未登录会话 / 第三方 Agent 通道」写死了单文件 50 MB 上限。

已逐条实测的通道：

| 通道 | 结果 |
| --- | --- |
| CLI `download` → `POST open-api-drive.quark.cn/open/v1/file/get_download_url` | `errno 23018 / download file size limit[52428800]`，与 88VIP 无关 |
| 进程内替换官方 PC 客户端 UA 后重跑 | 仍 23018，开放平台侧是硬限制 |
| CLI `read-file` | 本机 CLI 1.0.25 未实现该命令（文档超前于版本）；远端版本同为 1.0.25，无更新可升 |
| CLI `download list` / `resume` | 无历史任务可续 |
| 网页端分享页 `sharepage/token` + `sharepage/detail` | **可用**，免登录即可拿到 stoken、fid、文件名与大小 |
| 网页端 `file/download` 带 stoken | 跳过登录校验，但返回 `23018 / download file size limit[fid]` |
| 网页端 `file/download` 带官方客户端 UA / `share_fid_token` / 分片参数 | 均 23018（2026 年接口已收紧，客户端 UA 绕过法失效） |
| 本机夸克客户端 Cookie | 只有设备标识（`__uus` 等），无 `__pus`/`__puus` 会话；客户端启动后窗口为「首页」但未登录 |
| Chrome / Chrome Canary / Edge Cookie | 只有 `b-user-id`、`tfstk`、`isg` 等跟踪项，无会话 |
| 本地全盘检索 | 11-09 之后没有新增的这两个 IPA |

结论：**必须有一次账号身份认证**。登录态出现后，下面这个脚本会自动把剩下的全部做完。

## 一键自动下载脚本

`fetch_ipa.py`（同目录）会：自动从 Chrome / Edge / 夸克客户端读取并解密本机 Cookie → 校验分享链接 → 换取直链 → 带 Range 断点续传下载 → 校验字节数与 IPA 的 ZIP 结构。Cookie 只在本机内存里使用，不打印、不写盘、不外发。

```bash
cd /e/iOS-App-Analysis/01-IPA

python fetch_ipa.py --check          # 先看登录态是否就绪
python fetch_ipa.py                 # 就绪后全自动下载并校验
```

未就绪时提示如下，此时只需在浏览器或夸克客户端登录一次 `pan.quark.cn`，再重跑即可：

```
[未就绪] 没找到账号会话（__pus / __puus 等）。
```

也可以手动提供 Cookie 串（浏览器 F12 → Network → 任一 pan.quark.cn 请求 → 复制 Cookie 请求头）：

```bash
python fetch_ipa.py --cookie-string "粘贴的 Cookie 串"
```

## 下载完做一次校验

```bash
ls -lah /e/iOS-App-Analysis/01-IPA/
sha256sum /e/iOS-App-Analysis/01-IPA/*.ipa
```

两个文件大小对上表即可。然后运行：

```bash
cd /e/iOS-App-Analysis/03-Analysis && bash run-analysis.sh
```

会为两个 App 各生成一份 JSON + Markdown 结构体检报告到 `03-Analysis/reports/`。
