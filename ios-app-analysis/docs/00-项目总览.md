## 这个项目做什么

- 归档并**只读**分析本地 IPA 的包结构与 Mach-O 元数据
- 学习 iOS 二进制组织方式、加载命令、签名与加固现状
- 提供一套符合 Logos 规范的 Theos 工程骨架与本地菜单界面，用于教学与界面原型验证

## 明确的范围边界

本项目**不包含、也不打算包含**以下能力：

| 不做的事 | 原因 |
| --- | --- |
| 绕过付费 / 虚拟礼物 / 会员校验 | 规避技术措施，损害经营者合法权益 |
| 去除或屏蔽广告 | 干扰他人合法提供的网络服务正常运行 |
| 去除水印后保存他人图片、实况、视频 | 水印属于权利管理电子信息 |
| 阻止消息撤回 | 违背发送方意思表示，涉及他人通信与隐私 |
| 定位或改写第三方业务方法 | 会构成对他人软件的不当修改 |

依据是《著作权法》第 51 条、《计算机软件保护条例》第 24 条、《反不正当竞争法》互联网专条。上面这些属于"帮助侵害第三方权益"，因此不实现，也不提供定位到具体方法的指引。分析只停留在**结构、公开元数据与安全机制观察**层面。

## 环境实测结论（2026-11-09）

- `C:\theos\theos`：仓库本体 + `iPhoneOS16.5.sdk` 在位，LLVM clang、Strawberry perl、GnuWin32 make 也在
- 但 GnuWin32 是 Windows 原生 make，`$(shell uname -s)` 拿不到平台值，报
  `The "iphone" target is not supported on the "" platform`；且缺 `ldid` 与 iOS 交叉链接器
- WSL Ubuntu 24.04.3 已安装，但里面没有 Theos、make、clang、ldid、dpkg-deb
- 想真正编译出 `.deb`，推荐在 macOS / Linux / WSL 内安装 Theos 与对应工具链后执行：
  `make clean && make package`（详见 `04-Theos-Project/README.md`）
